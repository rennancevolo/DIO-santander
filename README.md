# ☕ Bootcamp Santander + DIO | Java

Este repositório reúne os códigos, exercícios e projetos desenvolvidos durante o **Bootcamp Santander + DIO**, com foco no aprendizado da linguagem **Java** e dos principais conceitos de programação.

## 📚 Conteúdo estudado

* Sintaxe básica do Java
* Variáveis e tipos de dados
* Operadores
* Estruturas de decisão (`if`, `switch`)
* Estruturas de repetição (`for`, `while`, `do-while`)
* Métodos
* Arrays
* Entrada de dados com `Scanner`
* Orientação a Objetos (em andamento)
* Exercícios práticos

## 🎯 Objetivo

Registrar minha evolução durante o bootcamp, praticar os conceitos aprendidos e manter um histórico dos exercícios e desafios realizados.

## 🛠️ Tecnologias

* Java
* JDK 21+
* IntelliJ IDEA / VS Code
* Git e GitHub

## 📌 Observação

Este repositório tem fins de estudo e prática. O código poderá ser atualizado e melhorado conforme avanço nos conteúdos do bootcamp.
